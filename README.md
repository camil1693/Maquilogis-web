# Sitio web de Maquilogis

Página pública de Maquilas Logísticas de Colombia S.A.S.: quiénes somos, portafolio de servicios, acceso al portal y contacto.

Se publica con GitHub Pages desde la rama `main` (carpeta raíz).

Los archivos se generan desde el proyecto principal con `construir-sitio.py`. Para cambiar el dominio, ajusta `URL_SITIO` en ese script y vuelve a generarlos.
